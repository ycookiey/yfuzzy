# yfuzzy (working name)

日本語特化のあいまい検索ライブラリ。ローマ字混じり入力、訓令式/ヘボン式並列、子音マッチ、誤字許容など、日本語UIの検索体験に必要な要素を1パッケージに統合。

## 状態

設計確定済み（2026-06-11）・実装前。仕様は `docs/spec.md`。

## スコープ

- 日本語特化（英字混在OK）
- **漢字は変換しない**（リテラル一致のみ。読みで検索させたい場合は `getText` で読み文字列を返す＝利用者責務）
- 短い文字列の単一フィールド検索
- ESMのみ
- UIは含めない（ロジックライブラリ）
- 規模汎用
